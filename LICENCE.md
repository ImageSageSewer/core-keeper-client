## 🧩 About

**Core Keeper Client** is a comprehensive overlay menu for Core Keeper featuring resource radar, ESP, loot tracker, and config editor.

Based on popular mods like **BepInEx**, **CoreKeeperMods**, and **QOLMod**.

---

## ✨ Features

### 🎮 Core Hacks
- Resource Radar — highlight nearby ores, chests, and items
- ESP — see enemies, NPCs, and loot through walls
- Loot Tracker — track rare drops and spawn rates
- Teleport — move to cursor or waypoints

### 🗺️ World & Survival
- Map Reveal — uncover the entire map
- No Clip — pass through terrain and obstacles
- Infinite Health — toggle god mode
- Instant Craft — craft without materials

### 🏋️ Utility & Config
- Overlay Menu — toggle features with hotkeys
- Config Editor — edit game settings easily
- Save Backup — backup and restore saves
- Co-op Support — works in multiplayer
